# 微醺时刻 · AFTER HOURS

适合朋友聚会的中文真心话大冒险网页应用，采用灰黑色与暖橙色界面，支持手机和电脑。

## 已实现

- **500 道完整题目**：200 道真心话、300 道大冒险，每题拥有唯一编号、适用性别及氛围标签。
- **先选执行者**：男生或女生；抽题池包含通用题与对应性别专属题。
- **三种玩法**：随机惊喜、真心话、大冒险，默认在适配题池内随机且不重复；题池耗尽后自动循环。
- **本地数据库**：首次加载将完整题库写入浏览器 IndexedDB。不需要服务器、账号、API Key 或外部题目接口。存储被禁用时，自动使用内置题库继续游戏。
- **聚会工具**：下一位、重新开局、题库分类与搜索、收藏、最近 500 条抽题记录、可选提示音。
- **本地保存**：收藏、设置、记录与去重状态存入当前浏览器的 localStorage，刷新后保留；重新开局保留收藏。

共有 445 道通用题、28 道男生专属题、27 道女生专属题。选择男生后可抽 473 道，女生可抽 472 道；500 是整份题库的总量。

## 直接打开网页版

运行 `npm run build:web`，生成独立文件 `dist/微醺时刻.html`。将这一个文件下载到设备后用现代浏览器打开即可，不需要 Node.js、开发服务器或联网；样式、脚本、图标与全部 500 道题目都已内嵌。也可以把该文件作为静态网页上传至网站托管服务。

`npm run test:web` 会重新生成文件，并在电脑与手机尺寸下验证导出文档：断网渲染、抽题、完整题库、分类、搜索、收藏和零外部网络请求。云环境的 Chromium 禁止直接导航至 `file://`，因此测试读取实际导出的 HTML 并在离线空白页面中执行，不依赖开发服务器。

## 发布为在线网页（GitHub Pages）

已准备 `.github/workflows/deploy-pages.yml`：向 `main` 推送后，或在 GitHub Actions 手动触发，将安装锁定依赖、运行题库测试、构建并部署静态网页。构建时自动设置仓库子路径，避免网站部署后找不到脚本和样式。

首次发布前，在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。将项目和工作流推送至仓库后，等待 Actions 中的发布流程完成，实际网址以部署步骤输出的 `page_url` 为准。对于当前仓库，默认地址预期为 `https://hajayyang.github.io/Truth-or-Dare/`；该地址只有在发布成功后才可使用。

本地可验证相同的发布构建：

```bash
npm run build -- --base=/Truth-or-Dare/
```

## 本地运行

需要 Node.js 20.19+ 或 22.12+；当前环境已使用 Node.js 24 验证。

```bash
cd /workspace/Truth-or-Dare
npm ci
npm run dev -- --port 5173
```

开发服务器监听 `0.0.0.0:5173`。

## 构建与验证

```bash
npm run build      # TypeScript 检查与生产构建，输出 dist/
npm test           # 抽题与题库单元测试
npm run test:e2e   # 桌面与手机浏览器端到端测试
npm run preview   # 预览生产构建
```

端到端测试自动构建并启动 `4173` 端口的生产预览。默认优先使用 `/usr/bin/chromium`；也可以设置 `CHROMIUM_PATH`，或运行 `npx playwright install chromium` 使用 Playwright 自带浏览器。

测试覆盖题库精确数量、ID/文本唯一、性别与题型筛选、去重与题池循环、抽题前性别校验、刷新保存、搜索收藏、真实 IndexedDB 初始化、禁用存储后的降级、动画中重开、设置弹窗及多种屏幕宽度。

## 项目结构

- `src/data/questions.ts`：完整的 500 道题目与类型定义。
- `src/lib/database.ts`：IndexedDB 初始化、读取及降级。
- `src/lib/game.ts`：随机抽题、性别/题型筛选和去重。
- `src/App.tsx`：游戏、题库、玩法说明及设置。
- `src/styles.css`：深色视觉与响应式布局，无外部字体或图片请求。
- `tests/app.spec.ts`：桌面与手机端到端测试。

此版本不包含云端同步或多人联网房间，适合同一现场轮流使用一台设备。游戏中任何题目都可以跳过，互动以前取得对方同意。
